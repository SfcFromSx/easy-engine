# Benchmark Test Matrix

This matrix inventories the benchmark module's non-trivial handwritten production logic and maps each meaningful branch to concrete automated tests.

## Scope Notes

- Boilerplate entities, enum accessors, repository interfaces, DTO field accessors, `BenchmarkApplication`, and simple config/property getter-setter classes are excluded because they are framework wiring with no meaningful handwritten branches.
- Private helper branches are traced through the public entrypoint that exercises them.
- Thin frontend methods that only delegate to `client.*`, Element Plus dialogs, or browser download/clipboard APIs are listed as exclusions when no benchmark-specific decision logic exists.
