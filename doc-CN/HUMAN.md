# HUMAN 操作规则

这是一个纯 agent 优先的工程。人类负责目标、审批、基础设施和恢复流程，但不应进行会破坏 agent 连续性的随意修改。

## 允许的人类操作

- 通过 `tasks.json` 或 `docs/exec-plans/` 调整目标与优先级。
- 使用 `.agent/PAUSE` 暂停或恢复自循环。
- 提供密钥、环境变量和基础设施。
- 审查 diff、补充验证、批准合并。
- 处理根 Git 初始化或嵌套仓库迁移等拓扑问题。

## 自循环运行时禁止

- 在当前任务之外手工改代码。
- 改写分支历史或强推。
- 直接修改 `.agent/` 运行态文件或 prompt 模板。
- 随意移动目录、删除任务文件或改生成文档。

## 手工修改前必须暂停

1. 创建 `.agent/PAUSE`
2. 等待当前循环停止
3. 完成手工修改
4. 记录原因
5. 确认环境稳定后再恢复
